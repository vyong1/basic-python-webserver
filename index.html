Available endpoints for managing items:

  • GET /health — Check server health.
  • GET /getItems/ — Get all items.
  • POST /putItem/ — Save an item.
  • PATCH /patchItem/ — Update an item.
  • DELETE /deleteItem/ — Delete an item.

Creating an item requires a string value; its integer id is generated automatically. Updates include the integer ID and value, and deletes include the integer ID.
